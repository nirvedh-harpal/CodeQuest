Setup Instructions

  1. Create a Google Sheet
    Go to Google Sheets and create a new spreadsheet for your questions.
  2. Open Apps Script Editor
    In your sheet, click Extensions Apps Script.
  3. Copy the Script Code
    Click the Copy Script Code button below to copy the complete Google Apps Script code to your clipboard.
    Copied to clipboard!
  4. Paste and Configure the Script
    • Paste the copied code into the Apps Script editor.
    • Find const SHEET_ID = "your-sheet-id-here"; and replace your-sheet-id-here with your actual sheet ID.
    • How to find your Sheet ID: In your sheet URL, it is the part between /d/ and /edit.
      Example: https://docs.google.com/spreadsheets/d/SHEET_ID_HERE/edit
    • You can also change the sheet tab name in the script if needed.
    • Save the script (Ctrl+S).
  5. Deploy as Web App
    • Click Deploy New Deployment.
    • For Type, select Web app.
    • Set Execute as: Me.
    • Set Who has access: Only myself (or Anyone if you want to use from other accounts).
    • Click Deploy.
    • Authorize access when prompted (choose your Google account, click Advanced, then Go to project (unsafe), and Allow).
  6. Copy and Save the Web App URL
    After deployment, copy the Web App URL shown. Paste it in the field below and click Save Configuration. The extension will automatically initialize your sheet with headers if it's empty.
  7. Start Using CodeQuest!
    Go to the problems page and start solving questions. Use the extension to save your questions directly to your Google Sheet.
